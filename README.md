# RahulMaida - Modern Zen Landing Page

A premium, fully animated landing page built with:
- **React 19** with TypeScript
- **Vite** for lightning-fast builds
- **Tailwind CSS 4** with custom theme
- **Framer Motion** for stunning animations
- **Lucide React** for beautiful icons

## Features

✨ Advanced 3D animations and tilt effects
🎨 Custom Zen theme with sage and gold colors
📱 Fully responsive design
⚡ Single-file build output with vite-plugin-singlefile
🔒 Zero ads, no key generators - Education for everyone

## Getting Started

```bash
npm install
npm run dev      # Start development server
npm run build    # Build for production
npm run preview  # Preview production build
```

## Deployment

The project is configured to build as a single HTML file using `vite-plugin-singlefile`.
Perfect for hosting on static hosting platforms.
